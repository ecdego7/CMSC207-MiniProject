# CMSC207 Mini-Project: Personal Web Profile


This is a single-page personal web profile created as part of the CMSC207: Web Programming and Development course of the Diploma in Computer Science of UPOU. This mini-project demonstrates HTML structure and semantics, CSS styling and JavaScript simple interactivity.

---

## Features:
-**Header and Naviagtion**: Site title, name and a simple navigation menu to each section of the website.
-**About Me**: A short introduction paragraph with an image included.
-**Hobbies and Interests**: Three sections with brief descriptions that include images and embedded media.
-**Contact Information**: Email, LinkedIn and Facebook links (placeholders)
-**Fun Fact Button**: JavaScript-enabled button displaying random fun facts, then disappears after a few seconds.
-**Mobile-Friendly Design**: The website used flexbox layout and media queries to ensure adaptability to different screen sizes.
